SINGLE PAGE — QUALITY ENGINEERING

An independent template inspired by the structure of the supplied reference.
This is an adaptation: the copy, illustrations and visual identity were recreated.
It does not use Accenture logos, photographs, client cases, business figures or profiles.

CUSTOMIZE
1. Open index.html in VS Code.
2. Find const EMPRESA and fill in nome (company name) and email.
3. Replace the remaining Your Company occurrences in the HTML, including the
   fallback text and title. Update the meta description as appropriate.
4. Review the services and tools to reflect your company's actual offering.
5. To add your logo, replace the symbol and name inside the .brand links.

PUBLISH TO YOUR HOST
1. Extract the ZIP on your computer.
2. Open public_html, www or your domain's public directory in your hosting panel.
3. Upload index.html into that directory. Back up any existing index.html first.
4. Visit your domain. For a subpage, use a directory such as
   public_html/quality-engineering/index.html.

No Node, WordPress, PHP, database or build step is required.
All CSS, JavaScript and CSS illustrations are included in the HTML.
No external fonts, images, trackers or scripts are loaded.
The contact button opens the visitor's email application; there is no message
submission backend. While the email setting is empty, the button displays a
contact setup notice.

FEATURES
Responsive desktop and mobile layout, anchor navigation, mobile menu,
expandable sections, keyboard focus indicators and reduced-motion support.

VALIDATION
HTML structure, internal links and JavaScript syntax checked automatically.
No browser visual verification was performed in this run. Review on a phone
and computer before promoting the page.
